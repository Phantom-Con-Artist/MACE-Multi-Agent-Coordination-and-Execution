# Mace 0.1.0 visual direction

The owner asked for an explorable landing page, illustrated setup, public manual, troubleshooting, docs and About. The current product is a native agent workspace controlled from a browser. The identity is MACE, Multi Agent Coordination and Execution. No em dashes in product copy. The user explicitly requests solid colors, geometric and non-Euclidean artwork, rounded pills, casual-user language, shadcn components and Lucide utility icons.

The governing relationship is one desk reached from another screen. A custom geometric illustration shows a stationary host linked to a handheld screen, with three agent shapes working around shared messages. The setup guide follows the actual operation: start the host, open the link, choose an agent. A step selector changes the accompanying illustration and instructions. Public navigation never requires authentication; only the actual workspace does.

References supplied by the owner: Echo geometric header and WunderUI dashboards on Dribbble, nualt.fr/en, orizon.one. Use their compositional relationships as references, not their wording or assets. The palette uses ink on off-white with lilac, chartreuse, apricot and blue geometric fields. Workspace panels use the same neutral surfaces and pill controls without reproducing WhatsApp's green bubbles or wallpaper.

Raster artwork is generated with the explicitly requested Codex Imagen skill. Lucide icons identify controls. The new Mace mark consists of two connected folded paths. Keep React/Vite and the existing working host APIs. Native dialogs retain modal focus behavior; shadcn primitives provide shared control styles and disclosures.

The strongest counterargument is decorative artwork over a generic page. The setup scene must explain the real three-step connection and the page must lead directly to the tested agent picker. No invented metrics, customers or claims of verified live provider accounts.
